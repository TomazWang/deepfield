## Reader feedback

Each `##` and `###` section heading has a 💬 feedback button.
Clicking it opens an inline [Giscus](https://giscus.app) discussion scoped to that section.

To enable feedback, configure `giscusRepo` / `giscusRepoId` / `giscusCategoryId` in `docusaurus.config.ts`
(or pass `--giscus-repo owner/repo` when running `deepfield docs build`).
